🧪 Lab Automation System

A complete Lab Automation Management System built using PHP and MySQL to manage product testing workflows, user roles, and structured reporting in a laboratory environment.

🚀 Features

👤 User Authentication (Admin / Tester roles)
📦 Product Management (Add, Edit, Delete, View)
🧪 Test Management System
📊 Test Result Tracking (Pass / Fail)
📄 Detailed Test Remarks Storage
🔎 Advanced Filtering & Reporting
🖨️ Print-ready Reports
🔐 Role-based Access Control
🛠️ Tech Stack
PHP (Core Backend)
MySQL (Database)
HTML5
CSS3
XAMPP (Local Server)

🏗️ Project Structure

lab_automation/
│
├── lab-system/
│   ├── db.php
│   ├── login.php
│   ├── logout.php
│   ├── dashboard.php
│
├── products/
├── tests/
├── users/
├── reports/
├── lab_automation.sql

⚙️ How It Works

Admin logs in to dashboard
Products are added and managed
Tests are assigned to products
Test results are recorded (Pass/Fail)
Reports are generated with filters
Data can be printed for lab records
📊 Database

Import the file:

lab_automation.sql

into phpMyAdmin.

▶️ How to Run
Install XAMPP
Start Apache & MySQL
Place project in htdocs
Import database file
Open:
http://localhost/lab_automation/lab-system/

This project was built as a final-year/portfolio system to simulate real-world laboratory testing workflow automation.
